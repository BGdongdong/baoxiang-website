# 后台管理使用手册

网站所有内容（文字、图片、产品信息、公司名称、Logo）均可在**不修改任何代码**的前提下，通过后台管理页面 `admin.html` 完成。

---

## 一、登录后台

1. **请使用 Chrome 或 Edge 浏览器**（后台需要浏览器提供的「本地文件读写」能力，暂不支持 360、QQ、Firefox 等浏览器）。
2. 打开网站文件夹中的 `admin.html`（双击，或部署后访问 `您的域名/admin.html`）。
3. 输入管理员密码登录。
   - **初始密码：`baoxiang2026`**

> 安全说明：后台登录为防误入的软门槛——后台只能编辑您自己电脑上的网站文件，不涉及线上数据；真正的发布权限掌握在托管平台（EdgeOne / GitHub）账号持有人手中。请妥善保管两类密码。

---

## 二、修改管理员密码（建议首次登录后立即修改）

1. 在 `admin.html` 登录页面按 `F12` 打开浏览器开发者工具，切换到「Console（控制台）」。
2. 粘贴以下代码并回车（把 `新密码` 三个字换成您想设置的密码）：

```js
(async () => {
  const t = new TextEncoder().encode(ADMIN_SALT + "新密码");
  const h = await crypto.subtle.digest("SHA-256", t);
  console.log("新哈希：", [...new Uint8Array(h)].map(b => b.toString(16).padStart(2, "0")).join(""));
})();
```

3. 复制输出的哈希字符串，用记事本打开 `js/admin/auth-config.js`，把 `ADMIN_HASH` 的值替换为新哈希，保存。
4. 重新打开 `admin.html` 用新密码登录验证。

---

## 三、选择网站文件夹（每次使用的第一步）

1. 登录后点击右上角 **「选择网站文件夹」**。
2. 在弹出的目录选择框中，选择**网站根目录**（即包含 `index.html` 的文件夹，例如 `D:\公司官网`）。
3. 系统校验通过后显示「✔ 已连接：公司官网」，即可开始编辑。
   - 浏览器会请求「查看和保存文件」权限，请点击「保存更改 / 允许」。
   - 下次打开后台时，点击同一按钮即可快速恢复（只需再授权一次）。
   - 若提示「不是网站根目录」，说明选错了文件夹——请选择 `index.html` 所在的那一层。

## 四、编辑内容（六个标签页）

| 标签页 | 可编辑内容 |
|--------|-----------|
| **站点信息** | 公司名称、简称、宣传口号、**公司 Logo**、电话、邮箱、ICP 备案号 |
| **首页** | 首屏大标题/副标题/主图、核心业务卡片、产品亮点、轮播图 |
| **关于我们** | 公司简介标题/副标题/段落、简介轮播图片（图片+说明） |
| **产品管理** | 各分类下的产品增删改：名称、图片、简介、图文详情、技术规格、产品特点、产品图库 |
| **联系方式** | 地址、电话、邮箱、工作时间、地图嵌入链接、微信二维码（右侧浮窗）、留言表单文案 |
| **SEO 设置** | 各页面的标题（title）与描述（description） |

**通用操作说明：**

- 所有文字字段均为「中文 / English」两栏并排，请同步维护两种语言。
- 带图片预览的字段可点击 **「上传图片」** 从电脑选择新图（支持 jpg / png / webp / svg，单张 ≤ 2MB），图片自动保存到网站的 `assets/img/uploads/` 文件夹。
- 列表类内容（轮播图、简介段落、产品等）通过 **「＋ 添加」** 按钮新增，每项右上角有 **「删除」** 按钮。
- **产品管理**中每个产品是一个可折叠卡片，点击标题展开编辑；「在此分类添加产品」可新增产品。

## 五、保存与发布

1. 所有修改完成后，点击右上角 **「保存全部修改」**。
   - 保存时系统会自动把旧数据备份为 `data/content.backup.js`，改坏了可以用它恢复。
   - 顶部状态会显示「● 有未保存的修改」，请养成随手保存的习惯。
2. 点击 **「预览网站」** 在本地查看效果（直接双击 `index.html` 也可以）。
3. 确认无误后，按《部署指南.md》第三节把更新后的文件上传到托管平台，线上网站即更新完成。

**「导出数据文件」按钮**：如果您使用的浏览器不支持本地读写（如 Firefox），可在支持 File System Access 的浏览器中编辑，或手工编辑后用此按钮导出 `content.js`，再手动替换网站 `data/` 目录下的同名文件。

## 六、常见问题

**Q：点「上传图片」没反应？**
请确认已选择网站文件夹、使用 Chrome/Edge 浏览器，且图片未超过 2MB。

**Q：保存时提示失败？**
检查是否选择了正确的网站根目录；关闭可能锁定文件的程序（如正在复制文件的资源管理器）。

**Q：改坏了想回退？**
用记事本打开 `data/content.backup.js`，全选复制内容，替换 `data/content.js` 的全部内容并保存即可回滚到上次保存前的版本。

**Q：后台页面会出现在搜索引擎里吗？**
已在 `robots.txt` 中声明禁止抓取 `admin.html`，正常情况下不会被收录。

**Q：留言表单的信息发到哪里？**
纯静态网站无法在服务器端收信。当前方案：访客提交后显示成功提示，并可一键通过邮件（mailto）发送到公司邮箱。如需服务器端真实收信，可后续接入 Formspree 等免费表单服务（需少量代码改动，联系开发人员即可）。
