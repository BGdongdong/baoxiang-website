# 素材替换说明

当前网站使用的是**工业风格占位图**（SVG 格式，深蓝 + 钢灰配色）。拿到真实素材（Logo、产品照片、车间照片、证书扫描件等）后，按以下方式替换即可，**无需修改任何代码**。

---

## 方式一：通过后台上传（推荐）

1. 用 Chrome/Edge 打开 `admin.html`，登录后选择网站文件夹。
2. 进入对应标签页（如「产品管理」→ 某产品 →「产品主图」→「上传图片」）。
3. 选择电脑上的真实照片，保存即可。上传的图片会存放在 `assets/img/uploads/` 文件夹。

> 优点：自动处理文件命名与路径，所见即所得。

---

## 方式二：直接替换同名文件

保持文件名不变，用真实图片覆盖占位图（建议先备份）：

| 占位文件 | 用途 |
|----------|------|
| `assets/img/logo.svg` | 公司 Logo（替换后建议同时更新 `favicon.svg` 网站图标） |
| `assets/img/hero-factory.svg` | 首页首屏主视觉 |
| `assets/img/products/*.svg` | 各产品主图 / 细节图 |
| `assets/img/about/workshop-*.svg` | 生产场景照片 |
| `assets/img/about/warehouse-*.svg` | 仓储场景照片 |
| `assets/img/about/patent-*.svg` | 专利证书扫描件 |
| `assets/img/about/cert-*.svg` | 资质证书扫描件 |

> 覆盖时可保留原文件名但换成 `.jpg/.png` 后缀——此时需在后台把对应图片路径改为新文件名；最省事的做法是**沿用占位图的原文件名**（包括扩展名）直接覆盖内容，或统一在后台上传。

---

## 图片规格建议

| 位置 | 建议尺寸 | 比例 | 格式 |
|------|----------|------|------|
| Logo | 高度 ≥ 128px | 任意（建议方形或横版） | SVG / PNG（透明底） |
| 首页主视觉 | 1600 × 900 | 16:9 | JPG（≤300KB） |
| 产品主图 | 800 × 600 | 4:3 | JPG（≤200KB） |
| 轮播图 | 1600 × 686 | 21:9 宽幅 | JPG（≤300KB） |
| 证书 / 专利 | 800 × 600 | 4:3 | JPG / PNG（≤200KB） |

**通用要求：**

- 单张图片不超过 **2MB**（后台上传会强制校验），网页展示建议压缩到 300KB 以内，保证加载速度。
- 可使用 https://tinypng.com 等免费工具批量压缩 JPG/PNG。
- 产品照片建议统一背景（白底或实景图均可），观感更专业。

---

## 替换后别忘了

1. 本地打开 `index.html` 预览确认。
2. 把更新后的文件夹（至少是 `assets/` 与 `data/content.js`）重新上传到托管平台（见《部署指南.md》第三节）。
3. 如有新增产品，请在后台「产品管理」中补充产品的中英文名称、简介与图文详情。
