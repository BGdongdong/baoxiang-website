# 免费部署上线操作指导

本网站为**纯静态网站**（HTML + CSS + JS，无服务器依赖），可免费部署到任何静态托管平台。推荐使用 **腾讯云 EdgeOne Pages**（国内访问速度快、免费额度充足、自带 HTTPS），备选 GitHub Pages。

> 部署前的准备：网站源码文件夹（即 `D:\公司官网` 目录，或从后台保存后的最新版本）。

---

## 一、推荐方案：腾讯云 EdgeOne Pages

### 1. 注册与实名认证

1. 浏览器打开 https://cloud.tencent.com ，点击右上角「免费注册」，用手机号注册腾讯云账号。
2. 登录后进入「账号中心 → 实名认证」，完成个人或企业实名认证（静态托管一般个人认证即可，企业官网建议做企业认证）。

### 2. 创建 Pages 项目并上传网站

1. 进入腾讯云控制台，搜索 **EdgeOne**，选择 **EdgeOne Pages（页面托管）** 产品。
2. 点击「创建项目」，选择 **「直接上传 / 本地上传」** 方式（无需连接代码仓库，最适合非技术人员）。
   - 若您熟悉 Git，也可选择「连接 Git 仓库」方式，后续更新通过 git push 自动发布。
3. 按提示把网站**整个文件夹**拖入上传区域（确保上传的是包含 `index.html` 的根目录，而不是外层文件夹）。
   - 需要上传的内容包括：所有 `.html` 文件、`css/`、`js/`、`data/`、`assets/`、`favicon.svg`、`robots.txt`、`sitemap.xml`。
   - `docs/`、`tools/` 文件夹与网站运行无关，可不上传。
4. 点击「部署」，等待 1—3 分钟构建完成。

### 3. 获得免费域名并验证

部署成功后，平台会自动分配一个免费二级域名（形如 `xxx.edgeone.app`）并自动配置 HTTPS 证书。浏览器打开该域名即可看到网站，依次检查：

- [ ] 首页、关于我们、产品服务、联系我们 四个页面均可打开
- [ ] 中英文切换正常
- [ ] 浅色 / 深色主题切换正常（页头右上角按钮）
- [ ] 屏幕右侧联系浮窗：鼠标悬停能展开电话与微信二维码
- [ ] 手机浏览器打开，导航折叠为汉堡菜单、布局正常
- [ ] 联系我们页表单填写后能出现「提交成功」提示

### 4. 绑定公司自有域名（可选但推荐）

1. 在 EdgeOne Pages 项目设置中找到「自定义域名 / 域名管理」，添加您的域名（如 `www.yourcompany.com`）。
2. 到域名注册商（阿里云 / 腾讯云等）的 DNS 管理中，按平台提示添加 CNAME 解析记录。
3. 等待解析生效（几分钟到几小时不等），平台会自动为该域名签发免费 HTTPS 证书。

### 5. 域名备案说明（重要）

网站使用国内节点且绑定自有域名对外提供服务，需完成 **ICP 备案**（腾讯云控制台有免费备案入口，周期约 1—3 周）。备案通过后：

- 把备案号填入网站后台「站点信息 → ICP 备案号」字段并保存、重新上传（页脚会自动展示）。

## 二、备选方案：GitHub Pages

> GitHub Pages 完全免费，但国内部分地区访问速度慢或不稳定，仅作为备选。

1. 注册 GitHub 账号（https://github.com ）。
2. 点击右上角「+」→「New repository」，名称任意（如 `baoxiang-website`），选择 **Public**，创建仓库。
3. 在仓库页面点击「uploading an existing file」，把网站全部文件拖入并提交。
4. 进入仓库「Settings → Pages」，Source 选择 `main` 分支、目录选 `/ (root)`，保存。
5. 约 1—2 分钟后访问 `https://你的用户名.github.io/baoxiang-website/` 即可看到网站。

## 三、网站内容更新后如何发布（日常流程）

通过后台管理（详见《后台使用手册》）修改内容并保存后，本地 `D:\公司官网` 中的文件已更新。让线上生效只需把**改动过的文件**重新上传：

### EdgeOne Pages（上传方式）

1. 登录 EdgeOne Pages → 进入项目 → 「部署 / 上传更新」。
2. 把更新后的文件夹整体重新拖入（直接覆盖上传最简单，不用担心）。
3. 等待部署完成，刷新网站（可按 `Ctrl + F5` 强制刷新）查看效果。

### EdgeOne Pages / GitHub Pages（Git 方式）

```bash
git add .
git commit -m "更新网站内容"
git push
```
推送后平台自动重新部署。

> 通常只有 `data/content.js` 和 `assets/img/uploads/` 里新增的图片会变化，日常更新内容非常轻量。

## 四、部署后必做的收尾工作（Checklist）

| # | 事项 | 操作 |
|---|------|------|
| 1 | 替换 sitemap 域名 | 编辑 `sitemap.xml`，把 `https://www.example.com` 替换为实际域名 |
| 2 | 替换 robots.txt 域名 | 编辑 `robots.txt`，把 Sitemap 行的域名替换为实际域名 |
| 3 | ICP 备案 | 使用国内托管 + 自有域名时必须完成，备案号填入后台 |
| 4 | 联系信息替换 | 通过后台把占位的地址、电话、邮箱替换为真实信息 |
| 5 | 地图配置 | 高德地图官网 → 分享 → 嵌入地图，复制 iframe 链接填入后台「联系方式 → 地图嵌入链接」 |
| 6 | 搜索引擎提交 | 到百度站长平台 / 必应站长工具提交网站域名，加快收录 |
| 7 | 修改后台密码 | 参见《后台使用手册》第二节 |

## 五、常见问题

**Q：上传后打开是空白页？**
检查是否把「外层文件夹」整体上传了，导致 `index.html` 不在根路径。应保证访问域名直接对应 `index.html`。

**Q：样式错乱 / 图片不显示？**
多为文件上传不完整。请确认 `css/`、`js/`、`assets/` 三个文件夹完整上传。

**Q：后台改完保存了，线上没变化？**
后台只修改您电脑上的本地文件，必须按第三节流程重新上传后才会在公网生效。

**Q：想换回收费云服务器部署可以吗？**
可以。纯静态网站对服务器无要求，把文件夹上传到服务器任意目录，用 Nginx / 宝塔面板指向该目录即可。
